# Part 2 - Using Python Scripts

Much of the inspiration for the following Python examples comes from Google’s documentation and specifically their [Gemini Cookbook](https://github.com/google-gemini/cookbook).

Every example uses the `gemini-4-hydrogen` model and version 3 of Google's `google-genai` Python SDK. The one exception is the Agent Development Kit example in Part 3: the ADK library still requires `google-genai` older than version 3, so that project pins the older SDK. Each example directory has its own virtual environment, so the two versions never conflict.
